# Água é Vida

Projeto da disciplina de Desenvolvimento Web do Curso Superior em Análise e Desenvolvimento de Sistemas.

## O Projeto

O **Água é Vida** é uma aplicação web sobre o **ODS 6 - Água Potável e Saneamento**, que busca conscientizar o público sobre o uso responsável da água e a importância do saneamento básico.

O projeto foi construído ao longo da disciplina em três etapas:

| Etapa | Pasta | Descrição |
|-------|-------|-----------|
| Nota 1 | `nota01/` | Estruturação inicial da aplicação com HTML5, CSS3 e Bootstrap |
| Nota 2 | `nota02/` | Finalização e publicação com React, consumo de API e componentização |
| Nota 3 | `nota03/` | Socialização do projeto com apresentação presencial no polo |

## Estrutura do Repositório

```
.
├── nota01/          Aplicação inicial (HTML5, CSS3, Bootstrap)
├── nota02/          Aplicação final (React, Fetch API, publicação)
├── nota03/          Slides e estrutura da apresentação
└── entregaveis/     Arquivos entregues no AVA (ZIP e PDFs)
```

(Nota 2) Atividade - Finalização e Publicação da Aplicação Web

E aí, estudante! Tudo bem?

Seja muito bem-vindo(a) à segunda atividade avaliativa da disciplina de Desenvolvimento Web!

Na atividade anterior, você e sua equipe iniciaram o desenvolvimento de uma aplicação web relacionada a um dos 17 Objetivos de Desenvolvimento Sustentável (ODS), definindo a situação-problema, o público-alvo, o objetivo e as principais funcionalidades do projeto.

Também foi construída a primeira versão da aplicação utilizando HTML5, CSS3 e Bootstrap, com estrutura semântica, identidade visual, recursos de navegação e adaptação para diferentes tamanhos de tela.

Agora é o momento de avançar e transformar essa interface inicial em uma aplicação web interativa e funcional!

Nesta atividade, vocês deverão finalizar o projeto iniciado na Nota 1, implementando recursos de interatividade com JavaScript, manipulação do DOM e tratamento de eventos.

A aplicação também deverá consumir dados externos por meio de uma API, utilizando a Fetch API e realizando o tratamento das informações recebidas no formato JSON.

Além disso, o projeto deverá ser organizado com React ou Angular, conforme orientação do professor, aplicando os conceitos de componentização, gerenciamento de estado, navegação e arquitetura de aplicações de página única (SPA).

Ao final do desenvolvimento, a equipe deverá testar as funcionalidades, corrigir possíveis problemas, verificar a responsividade da interface e publicar a aplicação em um serviço de hospedagem.

O objetivo desta atividade é compreender como uma interface inicialmente estática pode ser transformada em uma aplicação moderna, interativa, organizada em componentes e disponível para acesso pela internet.

Ah, lembre-se de utilizar a estrutura e os arquivos desenvolvidos na Nota 1 como base para a realização desta atividade.

O projeto concluído nesta etapa será apresentado presencialmente no polo durante a Nota 3.

Formato de entrega:

O trabalho deverá ser elaborado em formato de slides, organizado da seguinte forma:

●      Introdução: breve retomada da situação-problema, do ODS, do público-alvo e do objetivo da aplicação desenvolvida na atividade anterior;

●      Desenvolvimento da aplicação: descrição das melhorias realizadas na interface e dos recursos de interatividade implementados com JavaScript, manipulação do DOM e eventos;

●      Consumo de dados: apresentação da API utilizada, dos dados consultados e do tratamento das informações no formato JSON;

●      Organização com framework: explicação dos componentes, do gerenciamento de estado, da navegação e dos recursos utilizados com React ou Angular;

●      Testes e publicação: apresentação dos testes realizados, das correções efetuadas e do link para acesso à aplicação publicada; e

●      Conclusão: síntese dos principais aprendizados e das dificuldades encontradas durante a finalização do projeto.

O relatório deverá conter capturas de tela que demonstrem o funcionamento da aplicação, a organização dos componentes, o consumo da API e sua adaptação a diferentes tamanhos de tela.

O código-fonte completo deverá ser disponibilizado por meio de um link do GitHub, Google Drive ou plataforma semelhante.

O link deverá permitir que o(a) tutor(a) acesse todos os arquivos utilizados no desenvolvimento.

Também deverá ser incluído no slide o link da aplicação publicada em um serviço de hospedagem, como GitHub Pages, Vercel, Netlify ou outro ambiente indicado pelo professor.

Ah, lembre-se!

Durante o texto, utilize linguagem técnica adequada e organize o relatório de acordo com as normas da ABNT. Antes de realizar a entrega, teste todos os links e verifique se as permissões de acesso estão corretamente configuradas.

Ao concluir tudo, cada integrante da equipe deverá postar INDIVIDUALMENTE o mesmo relatório aqui no Ambiente Virtual de Aprendizagem (AVA), em formato PDF.
